# volare — coupled pack, boat and race model

Coupled electro-thermal pack model, boat dynamics and race simulation for the
Monaco Energy Class P50B 26S21P.

```bash
cd powertrain/python/volare
pip install numpy scipy matplotlib     # the only dependencies
python run.py                          # build everything
python verify.py                       # all five verification layers
```

See `../../QUICKSTART.md` for the full command table, `../../DATA_NEEDED.md`
for which numbers are still estimates, and `../../SABOTAGE.md` for how the
verification was itself validated.

## Two import styles, both supported

Modules import each other flatly (`import pack_thermal as pt`) and run directly
from inside this folder. `__init__.py` also puts this directory on `sys.path`
at import time, so `from volare.params import load` works from `powertrain/`.
Do not rewrite the flat imports.

## Paths

`params.py` resolves `project_root()` as two levels above this folder, which is
`powertrain/`. From there it reads `params/volare_params.json`, the single
source of truth that MATLAB and `cad/scripts/` also read. **This folder must
stay at `powertrain/python/volare/`.**

`figures/` is generated and git-ignored; `verify.py` rebuilds it in about eight
seconds. `celldata/p50b.json` is generated by `build_p50b_dataset.py` but is
tracked, because it is 14 KB and the invariants suite needs it on a fresh clone.
