# powertrain/params/

## volare_params.json — MISSING

This folder should hold `volare_params.json`, the single parameter file shared
between the MATLAB and Python sides of the project. **It was not part of the
upload and is not in the repository.**

It is read by:

- `powertrain/00_common/P50B_LoadParams.m`
- `cad/scripts/powertrain.py`
- `cad/scripts/layout.py`

and its absence blocks `cad/scripts/powertrain.py`, `cad/scripts/pack_fit.py`
and the MATLAB parameter checks in `SMOKE_TEST.m`.

`powertrain.py` refuses to substitute defaults, and that is the correct
behaviour: a CAD model built on invented dimensions looks authoritative and is
not. Do not add a placeholder file to make the error go away.

Also expected here, and also missing:

- `cells/p50b_derived.json`, generated by `tools/export_cell_tables.py`
  (which is itself missing).

Restoring `volare_params.json` is the single highest-value action available;
see `HANDOFF.md` section 5.
